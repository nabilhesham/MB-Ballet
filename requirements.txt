# Only imported when MB_DB_BACKEND=mongo, so a SQLite install that fails to
# download this still starts -- which is the reception laptop's case.
#
# Pinned to a floor, unlike everything else here, because the backend needs
# two things older releases lack: aggregation-pipeline updates (for
# merge_client_facts) and start_transaction. dnspython is a hard dependency
# of modern pymongo rather than the old [srv] extra, and mongodb+srv:// URIs
# do not resolve without it.
pymongo>=4.6

# Mozilla's root certificates, as a file. pymongo does not depend on it --
# only dnspython -- and a packaged build has no usable system CA store, so
# without this the macOS binary dies at startup with CERTIFICATE_VERIFY_FAILED
# against Atlas. See repo/mongo/client.py's ca_file().
certifi

# The door. Remote-unlocks the academy's EZVIZ DL05 after a check-in --
# see door.py.
#
# The marker is load-bearing rather than tidy: this package requires Python
# 3.12, and an unmarked line would make `pip install -r requirements.txt`
# fail outright on a 3.11 machine -- taking the whole app down over the one
# feature that is optional. Marked, a 3.11 laptop installs everything else
# and simply has no door, which door.py reports as a sentence rather than a
# crash. START.bat installs 3.12, so the reception laptop gets it.
pyezvizapi>=1.0.5.0; python_version >= "3.12"
